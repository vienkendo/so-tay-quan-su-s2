# Assets

Store static visual resources used by the Sổ Tay Quân Sư S2 interface here.

- `favicon.svg`: browser tab icon.
- `icons/`: reusable UI icons.
- `images/`: hero artwork, illustrations, screenshots, and other images.

Use relative paths from the site root, for example `assets/icons/example.svg` and `assets/images/example.webp`.
- `icons/books/`: icon công pháp (cắt từ màn Bảo Điển Kỳ Sách, 96×96 JPEG). Thêm icon mới: lưu file vào đây và khai báo trong `src/book_icons.json`, rồi chạy `python3 src/make.py`.
